---

## Reporting a Vulnerability

The DEFENCESYS team takes cybersecurity, data privacy, and zero-trust integrity seriously.

If you believe you have discovered a vulnerability, security bug, or unintended exposure:

1. **Do NOT open a public GitHub issue** to report security vulnerabilities.
2. Please privately report all findings to the lead architect, **Sanyam Gehlot**, via GitHub or private channel.
3. Include detailed steps to reproduce the vulnerability, including sample payloads, request headers, and relevant logs.
4. We aim to acknowledge receipt within 48 hours and provide a fix or mitigation within 7 business days.

---

## Cryptographic Non-Repudiation Notice

All AI assessment reports, frame logs, and phishing analysis verdicts generated by this platform are cryptographically sealed with an **ECDSA P-256** signature. 

If you detect any discrepancy where an ECDSA signature fails mathematical verification against the exported public key, treat the system state as potentially compromised and verify server certificate logs immediately.
